# RoboticDog

DIY 12DOF 四足机器人：先固定单腿台架，再实现平整室内地面上的低速遥控行走，之后研究仿真训练与策略部署。

## 当前阶段

2026-10-23：M0 进行中。交接包已接收并核验；硬件尚未到货。现有 C++17 v0.1 是离线软件原型，尚不能驱动真实设备。

本轮交付任务清单、包含硬件/执行器/输入协议适配边界的架构设计，以及本机基线测试和源码审查结果。M0 汇报后等待用户讨论确认，未经确认不进入 M1。

## 开发方式

主协调负责需求、架构、规格、完整差异审查和验收；实现与委派验证使用本地 Claude Code CLI，保留用户现有模型配置。每个有边界的实现任务采用独立工作树。

文档、测试和审查进度在有实质变化时提交并同步到此仓库。原始交接资料已入库，新的项目文档区分历史证据与当前验证结果。
