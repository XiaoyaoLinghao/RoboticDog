# 单腿 FK/IK：理想串联模型参考

## 使用边界

本模块是独立的、原创的 C++17 数学参考实现，不是经过验证的 RoboDog V2 运动学，也不是 LX-16A 控制程序。实际 STL 的自由度、齿轮、连杆、传动关系、关节轴线和尺寸尚未核实；真实机构甚至可能不是下面的直接串联结构。STM32F407 和三个 LX-16A 尚未到货，本文没有任何上机验证结论。

- 所有几何参数必须由调用者提供，没有实际硬件默认尺寸。
- 测试中的尺寸仅是人为构造的数学夹具，不能复制为实际腿参数。
- 输出是理想关节角，不是舵机角、位置单位、脉宽或命令。
- 不含轨迹、步态、限位、碰撞检查、负载校核、左右腿映射或传动/零位标定。
- 真实机械结构与传动校验未通过前，必须保持硬件运动路径禁用。单纯测试通过不解除任何硬件安全门槛。

## 1. 坐标、单位与零位

采用右手局部坐标系，原点位于髋滚转轴参考点：

- `+x`：前方；`+y`：模型的侧向正方向；`+z`：上方。
- 长度单位为米，角度单位为弧度；这里的“前方/侧向/上方”仅定义模型，不代表已测量的机器人安装方向。
- `r = hip_roll_rad`：绕 `+x` 的右手正转。
- `h = hip_pitch_rad`：绕滚转后的局部 `-y` 的右手正转。
- `k = knee_pitch_rad`：绕膝关节局部 `-y` 的右手正转，相对于大腿的相对角；不是小腿相对于机身的绝对角。
- `d = lateral_offset_m >= 0`：滚转后的局部 `+y` 方向偏置。
- `a = upper_length_m > 0`、`b = lower_length_m > 0`：两个理想俯仰连杆长度。

零位 `r=h=k=0` 时两段连杆竖直向下，足端为 `(0, d, -(a+b))`。正髋俯仰使直腿足端朝 `+x` 移动；正膝俯仰使小腿相对大腿朝 `+x` 弯折。正滚转把向下的伸长分量转向 `+y`。滚转也旋转侧向偏置，不能把 `d` 在世界坐标中固定不动。

负 `d` 不在本接口的参数约定内，会报无效几何；如需另一侧腿，应先独立验证其坐标变换和机械结构，不能据此假定简单镜像成立。

## 2. 正运动学推导

在尚未施加滚转的坐标中，令：

```
s = a sin(h) + b sin(h+k)
c = a cos(h) + b cos(h+k)
p_before_roll = (s, d, -c)
```

其中 `c` 是滚转前的向下伸长量，可以为正或负。施加右手绕 `+x` 的旋转得到：

```
x = s
y = d cos(r) + c sin(r)
z = d sin(r) - c cos(r)
```

这相当于先在局部 `+y` 方向经过偏置，再经过两个绕 `-y` 旋转的俯仰连杆，整体由髋滚转轴旋转。实现用三角和角公式计算 `sin(h+k)`、`cos(h+k)`，避免两个极大但有限角度相加溢出。

FK 在奇异姿态仍有定义，包括全伸直零位；有限且可表示的 FK 返回 `Ok`。这不代表该姿态可安全进行逆解或实机控制。

## 3. 逆运动学与四个分支

给定足端目标 `(x,y,z)`，定义：

```
rho = hypot(y,z)
|c| = sqrt((rho-d)(rho+d))
ell = hypot(x,c)
```

理想几何工作空间的必要且充分条件是：

```
rho >= d
|a-b| <= ell <= a+b
```

边界可以在几何上到达，但本逆解拒绝其中的奇异情况。代码先检查范围，不会把不可达目标投影、缩短或钳位到工作空间内。

### 滚转前竖直分支

- `VerticalBranch::Down`：选择 `c = +|c|`。
- `VerticalBranch::Up`：选择 `c = -|c|`。

`Down/Up` 描述的是滚转前的 `c` 符号，不是足端世界坐标 `z` 的符号。之后：

```
r = atan2(z,y) + atan2(c,d)
```

这是将 `(d,-c)` 旋转到 `(y,z)` 的角度。

### 膝分支

由余弦关系：

```
C = (ell^2-a^2-b^2)/(2ab)
S = +sqrt((1-C)(1+C))  对应 KneeBranch::Positive
S = -sqrt((1-C)(1+C))  对应 KneeBranch::Negative
k = atan2(S,C)
h = atan2(x,c) - atan2(bS,a+bC)
```

默认选择 `Positive + Down`。两个膝分支和两个竖直分支组合，给出此理想模型在非奇异点的四组解，角度按 `2*pi` 等价。输出统一到 `[-pi,pi)`。解不存在“自动选最近”、连续分支跟随或关节限位筛选；调用者切换分支可能导致角度不连续，本模块不提供运动过程。

在相同分支内，`IK(FK(q))` 应恢复原角度（模 `2*pi`）；在其他分支内，关节角可以不同，但 `FK(IK(p))` 应回到同一个目标。

## 4. 数值与错误约定

接口位于 `robot::kinematics`：

```
ForwardResult forward(const Geometry&, const JointAngles&) noexcept;
InverseResult inverse(const Geometry&, const FootPosition&,
                      KneeBranch = KneeBranch::Positive,
                      VerticalBranch = VerticalBranch::Down) noexcept;
```

返回结构分别含 `status + position`、`status + angles`。只有 `status == Status::Ok` 时输出可用。错误时输出清零只是确定性的无效占位值，不是有效零位指令。

状态含义：

- `InvalidGeometry`：任一几何量非有限、`d<0`，或任一俯仰连杆长度不大于零。
- `NonFiniteInput`：角度或目标坐标含 NaN/正负无穷。
- `InvalidBranch`：通过强制类型转换等方式传入不受支持的枚举值。
- `Unreachable`：目标超出上述理想几何工作空间；目标相对于几何尺度大到归一化溢出也必然不可达。
- `Singular`：逆解在奇异或所设数值近奇异范围内，不返回可用角度。
- `NumericalFailure`：有限输入的中间量/输出无法可靠表示、余弦运算超出有效域，或最终重建残差超标。

先校验几何，再校验目标/角度，最后校验逆解分支。长度在内部按最大几何量归一化，以降低平方溢出风险；极端比例造成的下溢仍会明确报错。`C` 不会钳位到 `[-1,1]`。浮点数不是精确实数，在边界附近不能承诺每个数学上可达目标都被接受；不确定时保守报错，不能用放宽目标或无视状态的方法自动驱动硬件。

对于角度次序 `(r,h,k)`，该模型位置雅可比行列式为：

```
det(J) = -c*a*b*sin(k)
```

因此 `c=0` 或膝全伸直/完全折叠时奇异。逆解还拒绝 `|c|/(a+b) <= 1e-10` 或 `|sin(k)| <= 1e-10`，并显式拒绝连杆距离的内、外边界。此阈值只是本数学实现的数值保护，不是实机安全余量。最终以 FK 重建目标，归一化残差不得超过 `256*epsilon(double)*(d+a+b)`。

实现无堆分配，无第三方依赖，不读取硬件，也不发送命令。需要标准 C++17 与标准数学库；在 STM32 上的工具链、`double` 代价、执行时间和数值表现均未验证，不能把主机通过等同于目标板通过。不要使用会破坏 NaN/Inf 检查语义的 `-ffast-math`。

## 5. 主机验证

从工程根目录单独构建并运行：

```
g++ -std=c++17 -Wall -Wextra -Wpedantic -Werror -O2 -DNDEBUG \
    -Iinclude src/kinematics.cpp tests/test_kinematics.cpp \
    -o /tmp/test_kinematics
/tmp/test_kinematics
```

测试使用始终执行的检查宏，不依赖会被 `NDEBUG` 禁用的 `assert`，失败返回非零退出码。覆盖已知姿态、正负方向、四个逆解分支、1000 组确定性随机姿态、同分支角度回环、目标坐标回环、零偏置、非有限值、非法几何/枚举、内外边界及其相邻不可达浮点数、奇异与近奇异目标、跨尺度及溢出/下溢保护。该验证范围完全限于本理想模型。
