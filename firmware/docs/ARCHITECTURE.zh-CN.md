# v0.1 架构与边界

## 分层

1. 目标来源：JointTargetSource::sample，输出 3 个关节的弧度目标、创建时间和运动时长。预留给本地调试、遥控策略和未来训练策略；这些具体生产者尚未实现。
2. SafetyGate：装载经确认的标定与限位，显式 arm 后检查实测反馈和目标，成功则一次返回完整 CommandPlan。失败清空结果并按情况锁存故障。
3. 将来的调度器：本版尚未实现。负责计划有效期、测量反馈、串行事务、故障停止、同步动作、负载管理；不能把 CommandPlan 当成已经执行。
4. ServoBus：一条总线同时只允许一个请求，进行非阻塞 TX→RX/完成，读取回应按 ID、命令和参数长度匹配；不自动重试。只允许有限命令子集。
5. Transport：具体 UART/收发器的非阻塞接口。当前唯一硬件模板 UnboundTransport 永远未就绪，不知道任何板卡引脚。
6. 理想化 kinematics：仅做数学计算，和上述执行链没有连接。实际几何与传动未验证前保持隔离。

## 数据与时钟

- 所有关节目标/反馈使用 rad；运动学距离用 m；原始舵机位置用 tick；时间用 ms。
- 时间戳取自同一单调 uint32 毫秒时钟，时间窗口必须在 1..2^31−1 ms。差值用无符号回绕计算；不得用壁钟或未经转换的网络时间戳。调用频率应远短于 2^31 ms。
- feedback.captured_ms 必须是三个关节中最早的真实测量采样时间，不能用命令生成时间代替；3 个关节的采样对齐、原始位置到关节角转换、过滤和可信度判定尚需集成。
- read POS 返回有符号 int16，超出正常命令位置范围也不能按 uint16 解码；上层需要判断校准范围和读数有效性。
- 每次 poll 至多读取 32 字节，parser 最多保留 22 字节，最多 16 个参数；未实现通用全指令协议解析。
- 跨 ISR/主循环必须由平台提供正确的有界队列及同步。核心类不具备线程安全性，不允许并发调用。

## 状态

- 上电 DISARMED。所有几何/电气/台架验证位均默认 false，ID 未指定，限位无有效值。
- configure 只允许在 DISARMED，失败则使配置无效；同一条腿的 ID 必须唯一。
- arm 要求有效配置、验证位和新鲜实测反馈。它不发送“加载力矩”。再次 arm 不续看门狗。
- plan 的输入含 NaN/Inf、过期/未来时间戳、越限、过大步幅/速度、错误时长时拒绝，并清空输出。校验基于量化后的实际 tick 目标；不存在静默裁剪。
- FAULT 必须显式 clear_fault 后回到 DISARMED，不能由 disarm 消除；clear_fault 不是自动重启授权。
- poll 看门狗只观察软件目标更新，不是硬件看门狗。上层必须持续调用，并把故障送入实际停止路径。
- 总线超时、取消和 I/O 错误会要求恢复。recover_after_quiet(true) 只应在调用方确实确认总线静默、旧回应已排除后调用；当前模板没有替你证明这一条件。

## 总线限制

- LX-16A 写指令无 ACK。WriteSent 仅说明传输完成，不能证明电机收到了、移动了或到位了。
- 协议没有序号。迟到的同 ID、同命令回应可能无法区分属于哪一次请求。清空缓存只能清理已经到达的数据，不可据此自动重试。
- 低层库不能阻止应用绕过 SafetyGate。它是给将来的审核过的执行层用的工具，不是安全隔离沙箱。已生成的 CommandPlan 不会被之后的 disarm/fault 自动撤销；执行时必须重新验证解锁、故障、计划时效及反馈，而不能只看 valid=true。
- ServoBus 不可复制/移动；Transport 必须比它活得更久。析构活跃总线会调用 abort；平台 abort 必须在返回前停止所有引用 packet 缓冲区的 DMA。
- 不允许在事务中重新利用发送缓冲区；poll_tx Complete 必须对应 UART 末尾停止位发出，而不只是 DMA 把数据搬入寄存器。
- 物理收发器切换需要精确到 UART TC 事件；主循环发现 Complete 太晚可能丢回复。适配器应在 TC 中断安全释放驱动、收集接收字节，enter_rx 不应丢弃已经到达的真实回复。

## 后续实现顺序

1. 核实板卡、电平与供电，构建 MCU 工程、时间源、日志、看门狗和可控电源急停。
2. 一次只接一个电机，先安全只读，再确认唯一 ID；本模板没有写 ID 工具。
3. 固定台架、确定机械自由度和传动；测量原始零位、方向、范围和斜率，建立可验证的 joint↔servo 映射。
4. 完成遥测监督、实时停止、串行调度和部分失败处理，再考虑小幅单关节动作。
5. 验证单腿 FK/IK、缓慢轨迹后，再扩展四腿、遥控和步态。训练策略另行搭建仿真、观测定义和安全封装，本版没有策略模型。
