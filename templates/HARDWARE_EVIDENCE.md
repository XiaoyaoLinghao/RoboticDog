# 硬件证据记录模板

这是待填写记录，不是已验证的硬件配置；空项表示未知，不表示默认通过。

- 记录日期与记录人：
- 硬件名称及完整型号：
- 版次/丝印/序列号（只记必要信息）：
- 照片文件及观察位置：
- 官方原理图/手册链接、版本、相关页：
- 与手中硬件一致的依据：
- 电源、接口电平、模式、线序证据：
- 电气/机械风险及保护方案：
- 使用仪器、测量条件、测量值及单位：
- 急停/断电和机械支撑验证：
- 已确认结论：
- 不确定或互相矛盾之处：
- 状态：UNKNOWN / VERIFIED_FOR_READ_ONLY / VERIFIED_FOR_SCOPED_TEST / BLOCKED
- 允许进入的具体测试阶段：
- 仍禁止的动作：
- 复核人/复核日期：

软件里的 verification=true 只能引用真实证据，不生成证据。这里填完也不自动改变任何程序配置或授权设备动作。
