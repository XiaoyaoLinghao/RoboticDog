# 关节标定记录模板

只能填写实测值；当前没有有效标定。不要抄 tests 中的 ID、zero_tick、方向、限位、速度、步幅和几何。此模板不是程序可直接导入的配置格式。

## 身份与模型

- 记录日期、测量人：
- 机械版本、打印文件固定版本/摘要：
- 腿与关节名称：
- 实物舵机型号/唯一 ID/总线归属：
- 关节轴线与正方向定义：
- 传动类型：未知 / 经验证独立线性 / 耦合 / 非线性
- 使用的 joint↔servo 模型及版本：
- 相关机构示意图/照片：

## 由证据建立的参数

- 机械零位及其定义：
- zero_tick、direction、ticks_per_rad（仅线性模型）：
- 拟合误差、回程间隙、适用范围：
- 机械极限与保守工作范围，均注明单位：
- tick 范围、速度、单次步幅及依据：
- 装配碰撞/线缆/齿轮限制：
- 失去力矩后的运动/跌落风险：
- 与真实 FK/IK 几何对应关系：

## 审核

- 单关节小幅试验条件和结果：
- 限位、急停、断线等测试证据：
- 生效配置版本/摘要：
- 状态：UNMEASURED / FITTED_NOT_VERIFIED / VERIFIED_FOR_SPECIFIC_BENCH
- 明确未通过或不能外推的场景：

不能仅凭线性拟合数值好看就忽略齿轮耦合、负载变形、机械干涉或动态误差。
