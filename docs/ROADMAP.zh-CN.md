# 项目路线与M0—M2任务清单

更新：2026-10-24，Asia/Shanghai。M0主机基线与独立审查已完成，用户已接受当前sanitizer覆盖限制；M1仅进入方案细化评审，开发尚未开始。具体方案见[M1执行链与HAL实施方案](M1_EXECUTION_PLAN.zh-CN.md)，确认前不实施。

## 已确认的项目决策

1. 第一阶段成果是固定单腿台架验证通过。单腿评审后再扩展整机投入。
2. 首个整机版本在平整室内地面低速遥控行走，不带额外载荷。
3. 核心采用单线程、轮询驱动、有界内存与工作量。M0—M2针对三关节独立线性映射；四腿与耦合映射保留扩展边界。
4. 硬件未到。先离线验证，后逐级实物准入。新增抽象层用于更换平台、电机与输入协议，不扩大本轮为通用机器人框架开发。
5. M0已汇报；2026-10-24用户接受sanitizer覆盖限制，要求先细化M1方案再讨论确认。该授权不包含M1开发。
6. 用户指定VS Code AI接手实现，本会话负责规格、编排与独立审查；本地Claude CLI已完成M0精确验证，VS Code仅整理该轮报告。用户授权的Build Tools/MSVC/SDK安装已完成。未来实现和限定CLI验证保持分离；硬件与烧录仍需准入及当次授权。

## 范围与统一完成定义

- M0—M2不实现四腿步态、真实遥控网络/串口驱动、STM32 HAL/烧录、实际标定、物理仿真或策略运行。
- C08拟合工具暂为NOT_IMPLEMENTED；Q组与B组真实板级能力不计本阶段完成。B01无真实设备依赖的默认边界持续检查。
- 每任务指定基线SHA、允许文件、禁止动作、验收ID与确切命令。委派按WORKFLOW执行，独立审查后接纳。
- 验收使用PASS/FAIL/NOT_IMPLEMENTED/NOT_RUN/BLOCKED，附证据。任务工作流另用TODO/IN_PROGRESS/DONE/AWAITING_USER，避免把“文档DONE”误读为功能PASS。
- 近期按任务滚动排期；M0结束后再估M1/M2，不沿用交接包中的8小时示意为工期承诺。
